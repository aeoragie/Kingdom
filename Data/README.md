# Data - 규칙 데이터

게임 규칙의 숫자를 담은 CSV.<br>
이 폴더의 CSV가 원본이다(엑셀 파일을 따로 두지 않는다).<br>
코어(`KingdomCore/Data/GameData.h`)가 읽고, 게임·콘솔 테스트·장래의 서버가 같은 파일을 쓴다.

## 편집 규칙

- **엑셀로 열어 고치고, "CSV UTF-8(쉼표로 분리)"로 저장한다**<br>
  그냥 "CSV"로 저장하면 한글이 CP949로 저장되어 로더가 거절한다
- **첫 줄은 열 이름**<br>
  열은 이름으로 찾으므로 순서를 바꿔도 된다.<br>
  열 이름을 바꾸면 코드도 바꿔야 한다
- **숫자는 정수만**<br>
  비율은 만분율로 쓰고 열 이름에 `BasisPoints`를 붙인다.<br>
  100 = 1%, 10000 = 100%
- **`Id`는 코드의 enum 이름과 같은 글자**<br>
  지형처럼 코드가 종류를 정한 표는 종류마다 정확히 한 줄이어야 한다
- **오류가 하나라도 있으면 게임이 시작하지 않는다**<br>
  어느 파일·몇 번째 줄·어느 열인지 오류 메시지에 나온다

## 표

| 파일 | 내용 | 열 |
|---|---|---|
| `Terrain.csv` | 지형 6종 | `Id`, `Name`, `MoveCost`, `DefenseBonusBasisPoints` |

`Terrain.csv`의 숫자는 자리만 채운 임시값이다.<br>
실제 값은 기획서 `12.미결수치`에서 필드 묶음 때 정한다.
