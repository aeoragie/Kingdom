# 한 줄 정의

**영역을 그려가며 땅을 개발하고, 성장하는 영웅으로 그 땅을 지키는 싱글 판타지**

삼국지 14의 헥스 영역 시스템을 기반으로 하되, 중세 판타지 세계관 / 영웅 성장 / 실시간 행동력 / 온라인 확장 가능 구조를 얹는다.

---

# 이 게임을 지탱하는 다섯 문장

1. **영역 전파가 전투이자 경제다.** 건물이 헥스 위에 올라가므로, 보급선 로직 하나가 전투와 경제를 동시에 지탱한다.
2. **핵심 긴장은 "확장할 것인가, 지킬 것인가."** 영역을 넓히면 부지가 늘지만 방어선이 길어진다.
3. **행동력이 모든 것의 화폐다.** 이동·건설·원정·임명이 같은 자원을 놓고 경쟁하고, 스탯은 곧 행동력 효율이다.
4. **판타지는 껍데기가 아니라 시스템이다.** 철광 → 제련소 → 장비 → 영웅 강화의 사슬이 "왜 저 산을 뺏어야 하는가"에 답한다.
5. **순수 C++ 코어 + UE5 뷰.** 이 분리가 계획 전체의 척추이고, 온라인 전환 가능성의 전부다.

| 승리 | 전 국가 멸망, 또는 국력 격차 (군사력 + 경제력 + 생산시설) |

# 현재 위치

**시스템 설계는 확정되었고, 남은 것은 개발하면서 맞추는 숫자다.** 착수를 막는 미결은 없다.

- 다음 할 일 — **Phase 0 착수**(모듈 분리). Phase 0~3.5가 수직 슬라이스, 1막 핵심 루프가 돌아가는 상태가 1차 목표
- 최대 난제 — AI 9개 세력, 손으로 안 잡히는 밸런싱(Phase 4 시뮬레이터로 조준), 경험 없는 UI
- 병행 검토 — UE가 담당하는 건 Phase 2와 10뿐이므로, 언리얼 학습 목적을 위해 작은 3인칭 샘플을 하나 병행
